## 🎯 What You Will Learn

### 🖥️ Frontend
- HTML5, CSS3, Responsive Design
- JavaScript (ES6+)
- React.js (Hooks, State, Routing)
- Real-world projects

### ⚙️ Backend
- Java + Spring Boot
- REST API development
- Security (JWT, OAuth2)
- Microservices architecture

### 🗄️ Database
- MySQL (Relational DB)
- MongoDB (NoSQL)
- Query optimization & design

### ⚙️ DevOps & Tools
- Git & GitHub
- Docker & Kubernetes
- CI/CD (Jenkins, GitHub Actions)
- System Design fundamentals
